# County Data Sources

Last updated: May 2026
Coverage: McHenry, Lake, Kane, DuPage, Cook counties — Illinois

## Illinois — General Notes
- Illinois assesses real property at 33 1/3% of fair market value.
  Assessed value x 3 (then adjusted by the county equalization
  multiplier) approximates fair market value. Assessed value is
  NOT market value — use it only as a cross-check.
- PIN = Property Index Number. Illinois county PINs are typically
  formatted XX-XX-XXX-XXX (some counties drop the dashes online).
- Assessment happens at the TOWNSHIP level; the township assessor
  site usually has the richest property characteristics (photos,
  sketches, comps). The county portal has tax and summary data.

## McHenry County, IL
- County tax/parcel portal: https://mchenryil.devnetwedge.com/
  Search by PIN, name, or address. Free. Assessed values, tax data.
- GIS / parcel viewer (Athena): linked from county portal — shows
  parcel shape, location, sales price/date.
- Recorder free web search: https://www.mchenrycountyil.gov/departments/county-recorder/public-records-search-options
  Free indexed land record search by name, PIN, address, doc number.
- Township assessors publish detailed characteristics; find the
  township from the PIN, then search that township's assessor site.
- PIN format: XX-XX-XXX-XXX (e.g. 01-01-011-011).

## Lake County, IL
- County property tax portal: https://tax.lakecountyil.gov/
  Search by PIN, address, or map. Free. Assessed values, tax data,
  sales history.
- Tax parcel viewer (map/GIS): https://maps.lakecountyil.gov/taxparcelviewer/
- Township assessor data (six townships): https://imslake.org/
  Covers Cuba, Ela, Grant, Libertyville, Shields, Vernon townships.
- Recorded land records (County Clerk): https://lake.il.publicsearch.us/
- PIN format: XX-XX-XXX-XXX.

## Kane County, IL
- County tax/parcel portal: https://kaneil.devnetwedge.com/
  Search by PIN, name, or address. Free. Assessed values, tax data.
- Assessment Office: https://assessments.kanecountyil.gov/
- Land Records Search (Recorder): https://lrs.kanecountyrecorder.net/
  Search recorded deeds by address, name, doc number.
- Township assessors set initial values; first two PIN digits
  indicate township.
- PIN format: XX-XX-XXX-XXX.

## DuPage County, IL
- County property lookup portal: https://www.dupageco.org/PropertyInfo/PropertyLookup.aspx
  Search by address, PIN, owner. Free. Tax + assessment data.
- Parcel viewer (GIS): https://gis.dupageco.org/parcelviewer/
- Recorder document search: https://recorder.dupageco.org/Search.aspx
- Township assessors hold the detailed building data. First two PIN
  digits = township: 01 Wayne, 02 Bloomingdale, 03 Addison,
  04 Winfield, 05 Milton, 06 York, 07 Naperville, 08 Lisle,
  09 & 10 Downers Grove.
- PIN format: XX-XX-XXX-XXX.

## Cook County, IL
- Assessor search (by address): https://www.cookcountyassessoril.gov/address-search
- Assessor advanced search: https://www.cookcountyassessoril.gov/search
  Free. Assessed valuation, property class, characteristics, sales tab.
- Cook County Property Tax Portal (unified — Assessor, Board of
  Review, Clerk, Recorder, Treasurer): https://www.cookcountypropertyinfo.com/
  Search by PIN. Single best starting point for Cook County.
- Recorded land records (County Clerk — absorbed the Recorder of
  Deeds in Dec 2020): https://www.cookcountyclerkil.gov/recordings/search-recordings
- CookViewer map tool (for sales comps): search by PIN without the
  last four digits, or by address/intersection.
- PIN format: XX-XX-XXX-XXXX (Cook PINs run 14 digits).
