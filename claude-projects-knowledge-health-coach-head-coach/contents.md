## Purpose

This knowledge base provides the health coach with reference material on fasting protocols, home-based exercise programming, and sleep optimization — the three pillars of the user's body recomposition work.

## How to Use This File

Consult this manifest first to locate the right source file for any question:

- For fasting questions (what to consume, electrolytes, when to stop, how to refeed) → fasting-protocols.md
- For exercise questions (movements, sets/reps, progressions, weekly structure) → home-exercise-library.md
- For sleep questions (schedule, environment, tracking, disruptors) → sleep-optimization.md
