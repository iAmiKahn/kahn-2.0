## How to Use

1. Start every major session by reading `SESSION_STATE.md` (in `04_memory_and_synthesis\`).

2. Reference `BINDING_CONTEXT.md` and `IDENTITY.md` for rules and who you are.

3. Work inside the relevant project or knowledge folder.

4. At the end of every session, update `SESSION_STATE.md` with new priorities, actions, and notes.

5. All changes are version-controlled via Git (once initialized).
