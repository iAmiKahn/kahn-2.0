# Project Knowledge Base — Contents Manifest

This file describes what each document in this knowledge base contains. Consult it to find the right source file for any question.

## File Index

| # | Filename | Contains |
|---|----------|----------|
| 1 | `contents.md` | This manifest — describes all files and their purposes |
| 2 | `mechanics-components.md` | Every component of a Claude Project: what it is, what it does, its limits, specifications |
| 3 | `mechanics-interactions.md` | How components interact with each other — the non-obvious relationships and dependencies |
| 4 | `craft-instructions.md` | How to write effective project instructions/custom prompts — patterns, anti-patterns, token economics |

## How to Use This Knowledge Base

- For "what is X?" or "what are the limits?" → `mechanics-components.md`
- For "how does X affect Y?" → `mechanics-interactions.md`
- For "how should I write instructions?" → `craft-instructions.md`
- For "how should I organize my project?" → `craft-organization.md`
- For "something isn't working" → `craft-failure-modes.md`
- For "what's the advanced way to do this?" → `advanced-patterns.md`
- For "does feature X work with feature Y?" → `feature-interactions.md`
- For "how do I keep this current?" → `maintenance-protocol.md`
- For "how do I verify this claim?" → `testing-protocol.md`
